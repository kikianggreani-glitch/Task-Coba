# Task-Coba
Belajar Visualisasi Data

## 📌 Deskripsi Proyek

Repositori ini berisi implementasi proses **visualisasi data dan analisis eksploratif (EDA)** menggunakan Python untuk memahami pola, distribusi, dan hubungan antar variabel dalam dataset. Proyek ini bertujuan untuk menyajikan data secara visual agar lebih mudah dianalisis sebelum masuk ke tahap pemodelan.

## ⚙️ Metodologi yang Digunakan

1. **Import Library**
   Menggunakan beberapa library utama seperti:

   * **Pandas** untuk manipulasi data
   * **NumPy** untuk operasi numerik
   * **Matplotlib** dan **Seaborn** untuk visualisasi data

2. **Load Dataset**
   Dataset dibaca menggunakan `pandas` dan ditampilkan untuk melihat struktur awal data.

3. **Eksplorasi Data Awal (EDA)**
   Melakukan:

   * Menampilkan beberapa baris data (`head()`)
   * Mengecek tipe data dan missing values
   * Statistik deskriptif untuk memahami karakteristik data

4. **Pembersihan Data (Data Cleaning)**

   * Menangani nilai kosong (missing values) jika ada
   * Memastikan format data sesuai untuk analisis

5. **Visualisasi Data**
   Beberapa teknik visualisasi yang digunakan:

   * **Histogram** → melihat distribusi data
   * **Boxplot** → mendeteksi outlier
   * **Scatter plot** → melihat hubungan antar variabel
   * **Heatmap korelasi** → mengetahui hubungan antar fitur

6. **Analisis Pola Data**
   Hasil visualisasi digunakan untuk:

   * Mengidentifikasi pola distribusi
   * Melihat hubungan antar variabel
   * Menemukan insight awal dari dataset
